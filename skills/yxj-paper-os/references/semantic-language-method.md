# 语义、信息推进与词族统计方法

这是按需选用的语境编码、信息推进与词族统计方法，配合已有机械统计；现有CLI不自动完成这些标签。按当前问题和已采用的项目约定选择维度、文本及是否需要参照。明确采用完整组合及五篇同刊方案时沿用其范围；其他分析不自动触发该方案。分类是可复核的操作定义，不冒称完整SFL分析、人工专家金标准或语言质量真值。

读前先固定输入与统计合同；按需定位：[范围与分母](#units)、[主语／角色／过程](#clauses)、[立场](#stance)、[信息推进](#flow)、[词族功能组](#lexical-families)、[复核与交付](#audit)、[版本兼容](#compatibility)。

<a id="units"></a>
## 范围、单位与分母

采用既有完整组合时，全文篇幅按正文＋随文附录的自然语言词数，含数学陈述和证明中的文字，规则见[量化分析](academic-language-comparison.md#default-statistics)。该组合的语义与词族样本是正文叙述段落，保留方法解释、结果讨论及结论；排除标题、摘要、贡献清单、正式数学陈述／证明、公式、图表／图注、参考文献及附录。作者或已有项目采用其他范围时，以实际合同为准，逐项标明差异；不能把叙述样本比例外推为全稿或证明质量。

先冻结来源与准备文本、章节／段界、句切分和纳排规则。TeX/PDF的载体不同不等于样本天然同口径：核对读序、参考文献挂接及正式数学材料是否确实剔除，记录残留及不可比范围。采用同一选择标准，但不能声称某次自动提取已把所有载体清理得同样完整。

句ID对应冻结的**句候选**，不是保证完整的自然句：缩写、公式或换页可切开一句，同一候选也可含两个自然句。语义判断回读完整段落，并按需回原TeX或PDF；恢复文字／数学含义只作为带定位的证据，不静默写入统计文本或增加候选。确需修正切分或段界时形成新输入版本，统一重建受影响的本稿／参照比较。

| 层 | 编码单位与互斥关系 | 默认主表分母与补充报告 |
|---|---|---|
| 主语所指、参与角色、过程 | 每个矩阵主句／有限并列主句一条；三个字段独立，各字段单标签 | 各字段自己的可判分句数；同时列总记录、未定／非语言占位数及占总记录比例。可判数为零时比例为缺失，不为零。 |
| 立场与互动 | 每个句候选一条，可多标签；未命中亦留记录 | 各类已确认命中数／全部候选，称已确认标签覆盖率；列可判数、状态和未定ID。未知不是已确认无标签，比例不可相加为100%。 |
| 信息推进 | 段首单列，其余每个原同段相邻句对一条、单标签 | 全部原相邻对，另报可判对及未定；不接跨段句对。 |
| 词项／词族／功能组 | 同一句内的有效匹配区间，另报命中句 | 次数与每千样本词密度；句覆盖以全部候选为分母。精确词项和去重统计分别保留。 |

立场`classification_status`至少区分`classifiable`、`partial`和`unresolved`：只有完整可判且标签为空才表示已查无命中。需要可判分母敏感性时，立场另报已确认命中数／可判候选数，推进另报各类数／可判对数，不能悄悄替换主表。部分标签可确认但整句仍未定时，保存逐标签可判身份，不能把同句其他空标签当作否定；可判敏感性应使用该标签的可判分母并说明规则。

保守的抽取碎片敏感性另冻结排除ID及逐条理由：只排除回源后仍无可独立理解的实质命题或操作指令的候选。数学命题、完整条件／定义、有内容的非标准句法不能因无有限动词而被排除。主语未定也不自动成为碎片。立场剔除所列候选；推进仅保留两端均未剔除的**原相邻对**，不跨缺口重接。不可靠时报告无法统一排除，而不强造清单。此分析不能修复错误段界或消除体裁、章节组成、证明残留与载体差异。

<a id="clauses"></a>
## 主语所指、参与角色与过程

### 切分

- 主句及并列的矩阵主句各一条。共享主语但各有独立有限谓词，或共享有限辅助动词且各有独立谓词内容的矩阵并列，默认**分别计录**，记录承接的主语／辅助动词。例如`We define the feasible set and compute its boundary.`计两条（`We define`、`[We] compute`），不合并为一条。
- 不展开条件、关系、宾语等从属分句；不把名词、形容词或非限定动词短语的并列提升为主句。目的不定式内部的`to compute and compare`仍在同一目的结构内。
- 标点不代替句法：冒号／分号后若有真实矩阵主句须计入，跨两自然句的候选亦然；`where/if`场景内的并列不因逗号或`and`成为矩阵主句。
- 独立`See/Note/Recall`等祈使句计隐含读者。`Let`编码其指令，不把受其控制的`denote/represent`等非限定补语另拆。
- 回源后仍无可编码主句的候选保留占位及状态，如`nonverbal_math`、`no_matrix_clause`或`unresolved_extraction`；不发明语言谓词，也不将它自动判为无意义。跨候选恢复同一主句须记录关联ID及锚点，避免重复编码。

每条用`句ID:c1`等连续编号，保存分句范围、字面主语／谓词锚点、承接来源和简短判断依据。识别主语所指、参与角色和过程是三次判断，不由一个标签推导另外两个。

### 主语所指 `subject_referent`

| 标签 | 所指对象 |
|---|---|
| `physical` | 车辆、队列、交通、物理输入输出或实际物理过程。 |
| `mathematical` | 响应、概率、分布、参数、频率、集合、条件等研究数量、表征或关系；有物理来源的量仍按该句所指归这里。 |
| `method` | 算法、程序、抽样／计算／优化等方法或操作机制。 |
| `evidence` | 作为显示／支持载体的图表、曲线、结果、定理、文献或论文内容；曲线作为数学对象时不因其在图中而自动归此。 |
| `human` | 作者、被引研究者、设计者、读者等人或人群，含可恢复的隐含读者。 |
| `dummy` | 无实指的it/there；可恢复的this/it按实际所指分类。 |
| `unclear` | 在已读语境和来源中仍不能可靠确定。 |

例如实际车辆和描述车辆的参数不是同一对象类别。数学／人主语比例只是上述类别的统计，不等于客观性、作者身份或文章质量判断。

### 参与角色 `participant_role`

| 标签 | 在该命题中的作用 |
|---|---|
| `actor` | 行动、变化或因果作用的发起主体。 |
| `affected` | 被计算、选择、改变、测量、界定或推导的对象。 |
| `carrier` | 身份、属性或静态关系的载体。 |
| `evidence_source` | 本句用来展示、证明、报道的材料／来源。 |
| `experiencer` | 知道、判断、考虑等认知的主体。 |
| `existent` | 存在陈述中的对象。 |
| `dummy` / `unclear` | 无实指语法主语／无法可靠确定。 |

主动语态不等于actor，被动语态也不一律为affected。按实际语法主语编码，不把省略的施事替换成主语；静态数学表示常为carrier。语态可另报，不与角色分母混用。

### 过程 `process_type`

| 标签 | 主句谓词的实际功能 |
|---|---|
| `relational` | 定义、属性、身份、包含、对应、静态依赖或充分条件等数学关系。 |
| `change_effect` | 变化、传播、增减、影响、因果或机制作用；包括分布、配置及概率的变化，不限车辆运动。 |
| `operation` | 构造、计算、选择、抽样、优化、测量或设置模型／实验前提等操作。 |
| `evidence_argument` | 展示、说明、证明、推导、报道等证据或论证行为。 |
| `cognition` | 知道、认为、理解、考虑或研究意图。 |
| `existence` | 存在、出现或可用性的陈述。 |
| `unclear` | 无法可靠确定。 |

`give/yield/determine/allow/show`不能按词形一律判操作、作用或论证。主动的数学等同可为关系；`defined as`可为carrier／relational，实际被推导／证明则可为affected／evidence_argument。显式`we assume`若在设置前提，按操作而非个人信念；`we suspect`才检查认知及认识保留。`is worth noting`的矩阵谓词是关系属性，`should be noted`检查被动注意／指引，`it follows`按实际推导判断。

过程统计只看矩阵层。带显式图证的“概率下降”可仍为change_effect，同时在句级计显式证据E；反之，一个展示主句不保证全句各项主张都有证据。两种分子和分母不可互换，更不能由叙述样本中论证过程较少推出正式证明不足。

<a id="stance"></a>
## 立场、条件与互动

逐句结合完整段落编码以下全部标签；保留标签跨度、理由、证据来源及未定／边界，不只编码检索命中句。

| 标签 | 纳入与关键排除 |
|---|---|
| `epistemic_hedge` | 对命题真实性、证据确定程度的显式保留。保存保留者holder，区分本文作者与被引作者；can/may能力、数学可能值、近似舍入不自动纳入。 |
| `model_condition` | 实质前提、范围、适用域、已知／未知量或量词限制。这里“实质条件”不宣称逻辑上都是必要条件；按原文保留充分／必要、有限／极限等强度。 |
| `technical_possibility` | 数学／物理能力、可行性或结果的技术可能性；不能因为may/can出现就同时计认识保留。 |
| `evidential_assertion` | 有可核对的图表、结果、推导、证明或文献挂接支持本句命题；普通肯定、方法操作和孤立数字不自动纳入。 |
| `evaluation` | 对效果、重要性、代价、优势、不足或比较对象作实质判断。须指出比较尺度／对象或评价依据；不等于自夸或best等形容词，单独报数、设条件、选取可行点不自动纳入。 |
| `reader_guidance` | 面向读者的设定、考虑、回忆、注意或阅读定位；与科学所需的方法操作可同句并存。 |
| `open_question` | 明确尚未解决的问题、数据缺口或未来研究。区分背景提问、本文拟解问题与结尾仍开放的问题，不能把所有问句当作未完成工作。 |
| `defensive_generic` | 没有新增科学信息的泛化自我保护、免责声明或重复非蕴涵提醒；不能把首次必要范围说明、误差、负面结果自动归此。 |
| `claim_retreat` | 相邻论述反复“主张—撤回／防御性弱化”，且没有新的科学依据承担该退让。记录所关联主张ID、撤回内容及为何是防御；真实条件化、证据更新或诚实纠错不自动纳入。 |

科学条件、认识保留、证据与评价可以同句存在。负面结果、跨阈值区间不能认证、具体误差界是科学信息，不自动成为防御／撤回；也不能为增加评价而把“不能认证”改成真实概率必不达标。

### 显式证据的归属

分别保存`visible_text`（本句显式载体／推导）、`context_link`（明确连续论证）、`tex_citation`或`pdf_citation`（直接文献挂接）。TeX/PDF两种citation在语义上等价，按来源载体保留方法身份，可同句多来源；仅靠直接文献纳入的标记`citation_only`，另报其与可见／上下文证据的覆盖，不能相加为互斥总数。

原句没重复Fig./Results但确实继续报告同一图／结果时，可计E；必须保存关联句ID、支持命题、定位及可核对的`contextual_support`，不能整段自动继承首句证据。数学推导须有可恢复的推理链，不能把所有公式或肯定句当作E。

直接引文须核本次命题的实际附着。相同文献在一篇内多次出现时，不能把较早引用的页／行贴给后来命题；跨页引用记录实际两页。保存原TeX位置或PDF页和证据原文，机械定位匹配只证明位置相符，不代替支持关系判读。

### 指引、防御与内部用语

`See Fig.`、`Consider`、`Recall`是合法读者指引，不因属于互动而判内部话语。运行编号、编辑／验收状态等是否进入论文，应按实际科学含义审读；有正式学科含义的baseline等词不能仅凭词形禁用。禁止泛化防御及内部工作语言仍是独立的内容要求，不因D／撤回低或为零就免查，也不能用一个比例证明已经消除。

<a id="flow"></a>
## 同段信息推进

每句先写简洁`topic`，说明当前主要讨论对象；它不等于形式主语，也不是完整Theme/Rheme或given/new标注。对非段首句记录原前句ID，连读本段后选一个主标签：

| 标签 | 关系与所需依据 |
|---|---|
| `constant` | 延续上句主要对象，增加性质、结果或解释。 |
| `linear` | 把上句新引入的结果、关系或成分作为本句主要对象，指明其来源。 |
| `derived` | 两句是同段具体总题的不同方面、成分或案例；保存总题和两方面，不能只写“同属本研究”。 |
| `framed_shift` | 条件、对比、步骤或问题转换框定新焦点；指明实际连接。 |
| `weak_link` | 缺失读者理解所必需的连接或指称，写明缺了什么；没有连词、对象改变或需要回看本段前句并不充分。 |
| `unclear` | 数学抽取、指称或可辩分类边界使关系不能可靠确定。 |

段首保存`paragraph_start`身份，不把它计入与前段末句的同段推进。多种关系均可解释时记录首选及边界，不强造唯一真值。weak_link低或零不是总体连贯性或文章通过证明。

<a id="lexical-families"></a>
## 词族与功能组

精确词项仍依[内置和补充词表](academic-language-comparison.md#default-statistics)保留原次数／密度；词族层不能覆盖它。默认功能组为：对照让步、因果推导、补充递进、伴随条件、举例解释、强调与读者提示、限定程度、总结回指、解释动词。内置其他类别也保留其原身份；中文或其他语言用相应词表与分词／单位规则，不能把英文映射自动当翻译等价。

保存实际词项→词族→组的配置、版本和哈希。解释动词等可显式列屈折形，不自动扩展语义近义词或用未记录的词干化。`as/while/with`等多义词的命中仅是字面筛查，不等于语义功能已核定。

每篇在同一句内匹配，保留大小写、词边界／词形规则和起止位置。默认从左到右取非重叠匹配，同起点优先较长者，再按词族／词项名的字典序打破平手，并将具体排序写入配置；分别在每个组内和全表执行。记录同一命中在哪层被选中，旧项目已有其他确定性规则时沿用并明示，不能混算参照。不同组可覆盖同一区间，组的总和不等于全表唯一命中。

逐篇至少交付：原始精确词项数、归并词族数、组内去重数、全表去重数、命中句数／覆盖率、样本词数及每千词密度。参照范围要从每篇实际组／族结果取得，不能相加各词的极值。所有同类频率保持同一分母；全文词数与叙述样本词数不混用。词族命中句覆盖另保留句分母，不能把词项密度区间直接套给它。

<a id="audit"></a>
## 执行、复核与交付

先冻结输入／方法，再完成声明范围的初编码，包括未命中和不能判断的单位，最后按风险复核与纠错。只检索关键词或只看命中句时，结果只属于这些候选；不能作为默认全文语义分布。确实只能抽样时，报告抽样设计、权重、适用误差及局限，标记全覆盖编码尚未完成。

复核规模随风险，不要求固定模型品牌、推理档位或多执行者。选用立场分析时逐例回读认识保留、泛化防御和主张撤回命中；对各所选维度回读未定、uncertain／borderline和抽取边界，并按实际范围设置可复现的分层样本，记录位置／步长和去重规则。采用原有完整组合时，沿用其覆盖引言、理论／方法、结果和结尾的分层要求。抽样发现系统性分句、角色、证据或推进错误时，扩查受影响结构／类别并一致纠错。只有实际检查的ID才算复核覆盖，不把计划样本或模型同意当完成。

所选维度的审计材料放在项目已有统计／评审产物位置，名称可沿用现行约定；下表按实际分析选择相应项目：

| 材料 | 必须可恢复的信息 |
|---|---|
| 输入锁与方法 | 文档ID、来源／版本、源文件及准备文本哈希、纳排范围、段界句界、词数单位、标签定义与版本、词表／去重配置；程序、解析模型／版本，语境编码方式及实际使用的模型／人工方法。方法记录身份，不规定品牌。 |
| 单位与定位 | 候选ID、段／章、准备后文本及原TeX行或PDF页；回源恢复的原文／数学与关联ID。不能把准备文本偏移冒称原PDF坐标。 |
| 主语／过程表 | 分句ID和跨度、字面主谓锚点、承接来源、三个独立字段、逐字段可判状态、依据和边界。 |
| 立场表 | 所有候选、标签及跨度、分类状态／未定、holder、证据挂接类型／定位／关联ID、撤回所关联主张及理由。 |
| 推进表 | 所有候选的话题、段首身份；原前句ID、单一关系、具体总题／连接依据及未定。 |
| 词族表 | 精确命中区间、词形／族／组、组内和全表选中身份、配置哈希及逐篇密度。 |
| 复核与变更 | 真实检查ID、维度、来源和审读层级（自核／独立／抽样／全量）、扩审原因；before/after、纠错理由、变更数、未解决项及最终输出哈希／路径。 |
| 汇总与敏感性 | 每篇分子／分母、总数／可判／未定、均值／极值、缺失及有效篇数；如做碎片排除，保存逐条ID和理由、原相邻对筛选方法及剩余限制。 |

逐篇先归一化，再等权求均值和min–max；采用该方案时与[参照区间](academic-language-comparison.md#reference-ranges)一致。三个分句字段、句级多标签、邻对比例是非词项指标；词族／功能组每千词密度属于词项频率，不能互换区间规则。比较须同单位、同纳排／分母，缺少可比项时报告缺口而不伪造差值。

解释差异时返回章段和原句，指出叙述职责及限制。数学对象主语多不自动要求改成人；变化过程多不自动要求把机制塞进show从句；E或评价增加须来自真实证据挂接、比较对象及其含义。数字、条件、操作或形容词不能为凑标签升级为评价。定量不覆盖科学内容、正式证明、模型域、数据与引用支持的审读。

修改后候选、分句和词数分母可能联动，必须提取实际新稿并重标受影响单位／语境，再重算相关整组。旧句ID可映射到新ID，一对多／多对一如实记录；不得固定旧分母投影、改分类或删难判项来宣称达标。原样且语境未变的编码可在哈希和映射核对后复用，变更后的结果不继承旧版本通过。最终只有明确采用的硬门槛要求同一版本联合验收。

<a id="compatibility"></a>
## 既有口径兼容边界

- 旧字段`subject_role`若实际指所指对象，可映射为`subject_referent`；不得与`participant_role`合并。旧标签缩写先保存映射和原件，不按名称猜义。
- 旧项目若已冻结其他共享主语／辅助动词的并列切分规则，须声明差异，并在同一比较版本的本稿及全部参照中统一执行；不能混算不同规则或版本的分母／比例。改采本默认规则时，另建版本，统一重切、重标受影响单位并重算，保留旧原件与结果。
- 旧主句统计若用全部记录作分母，保留原报告；能从原记录统一取得可判分母时另交同批更正版并说明分子／分母变化，不能把新旧比例静默拼接。
- `tex_citation/pdf_citation`按载体保留，语义等价；旧E若漏直接挂接或过度继承上下文，需要有原页证据的更正，不能据现表空值假定没有证据。
- 旧立场表若没有状态，只在已有完整编码记录确实支持时解释为classifiable；缺标签不自动代表已查无标签。抽取未定与已确认无命中分别保留。
- 原精确词项、词形族和去重规则各有版本身份。新增默认族／组不重写旧精确结果；跨版本比较须复算同一配置，不能把新归并数和旧原始数相减。
- 默认范围或方法升级只影响新采用的合同。保留历史输入、旧报告和原门槛身份；不追改历史通过，也不把某篇论文的比例目标或某批期刊数值固化为通用门槛。
