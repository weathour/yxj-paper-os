# 量化分析与文献对照

按写作问题、用户要求或项目已有约定，选用单篇／批次统计、版本比较、语义分析或发表文献对照。整稿交付本身不自动启动完整统计包或期刊参照；已明确采用的指标、口径和门槛继续执行。报告实际选择的对象、方法、结果和写作含义。

按需定位：[按任务选用](#delivery-acceptance)、[可选统计组合与词表](#default-statistics)、[语义编码与审计](semantic-language-method.md)、[期刊参照与区间](#reference-ranges)、[计数方法](#执行顺序)、[程序与任务](#现成程序与任务路由)、[八方面口径](#指标口径速查)、[限定与防御性](#限定与防御性的语境判断)、[文献数值](#可核对的文献数值锚点)、[结果读取](#结果呈现与边界)。

<a id="delivery-acceptance"></a>
<a id="在整稿流程中设计和完成量化验收"></a>
## 按任务选用量化分析

先确定要回答的写作问题、指定指标或已有项目要求，再选择范围、方法及是否需要参照。单篇描述、版本比较或局部诊断可以独立执行；下方完整组合和五篇期刊参照是可明确采用的方案，不是所有整稿或所有比较的前提。期刊篇幅限制及作者、项目已采用的指标和门槛按其实际要求落实。

采用某项分析时，核对实际稿件版本、提取范围、指标定义和分母。统计定位值得解释的章段与原句，回读语境和科学含义后再决定是否修改；词频不能替代对禁令、条件或来源的语境审读。修改影响分子、分母或共用文本时重算受影响结果，并让已采用的硬门槛对应最终稿。已有门槛与编辑范围冲突时，明确具体冲突，处理可独立完成的部分。

## 可选完整统计组合与补充词表

下表描述可明确选用的完整组合；也可按问题只选择其中的指标。已采用此组合的项目继续沿用其范围和要求。

| 组合部分 | 统计内容与范围 |
|---|---|
| 全文篇幅 | 正文＋随文附录的自然语言总词数，同时报正文、附录分项；包含数学陈述和证明中的文字，标题、摘要、图表及图注、参考文献、数学表达式另计。随文附录缺件时标明总量不完整，不把缺失当作零。独立补充材料另列，期刊或作者规定其他口径时同时报告其要求。 |
| 句段与词汇 | 词句段数量，句长和段长的均值、分位数、SD／CV、长句比例；MATTR50、三词串／四词串重复种类占比、句首词项类型比、相邻句Jaccard。其他基础输出保留供定位。叙述样本与全文词数分开，明确数学陈述、证明等是否进入语言样本。 |
| 英文词性与句法 | 选择该组合时启用 `--nlp syntax`，包含词性密度、从句及关系从句候选、名词前后修饰链接、被动结构候选，同时保留主谓头距离、this/these词性、时态及完成／进行等输出。模型或语言能力缺失时列明待完成项，不退回基础统计后声称已全部完成。 |
| 词语与固定短语 | 选择该组合时同时运行程序内置字面词表和[英文补充词表](../assets/language-terms-en.txt)。逐项保留次数、统计词数、每千词密度及定位，包括零出现项；本稿和参照使用同一词表及文本口径。 |
| 主语所指、参与角色与过程 | 对叙述样本的矩阵主句及有限并列分句，分别统计数学／人／物理／方法／证据／无实指主语，actor／affected／carrier等参与角色，以及关系、变化／传播／影响、操作、展示／证明／论证、认知、存在过程；三个字段独立编码，各报可判分母、总记录及未定。 |
| 立场与互动 | 按全部句候选多标签统计认识保留、实质条件、技术可能、显式证据支持、评价／比较、读者指引、开放问题、泛化防御及主张撤回。报告已确认覆盖率、未定身份、证据来源和边界，不用词表代替语境。 |
| 信息推进 | 区分主要话题与形式主语；段首单列，以同段原相邻句对统计同题延续、线性、同总题派生、框定转换、连接不足及未定。 |
| 词族与功能组 | 在精确词项之外，显式映射词形族，该组合汇总补充词表九组；逐篇报告原词项、词族、组内与全表去重、命中句覆盖及每千词密度。字面功能组不等于已核定语义标签。 |

选用语义维度或词族汇总时，按[语义统计方法](semantic-language-method.md)覆盖声明的本稿和参照范围，并保持可比口径。语义初编码须覆盖声明的统计单位，复核按实际风险和账本范围报告；语境编码不同于运行词表。所选能力缺失时如实报告，不能填零或将基础统计称作完整组合。

英文补充词表包含80项，覆盖对照让步、因果推导、补充递进、伴随条件、举例解释、强调与读者提示、限定程度、总结回指、解释动词九组。按任务可扩充，记录实际词表及版本；它补充内置词表，不替换内置类别。中文使用对应语言的词表，不能把英文词表漏检当作中文零出现。

精确词项默认不区分大小写，不归并词形；`show`和`shows`分别计数。`so`与`so that`、`with`与`together with`等嵌套项允许各自命中，不能直接相加为总次数。默认词族／功能组层另行规定词形映射及最长匹配去重，对每篇计算后再取得范围；不得覆盖精确词项结果，也不能相加各词的最小值和最大值。配置与去重细则见[方法参考](semantic-language-method.md#lexical-families)。

## 可选的目标期刊参照方案

当用户或项目明确采用既有五篇参照方案时，使用**至少五篇目标期刊、同文章类型**的完整文章，语言及科学贡献类型也应可比；复用合格的已有材料，记录来源和正文／附录范围，缺少适用参照时说明。以下区间属于该已选方案，既有项目的明确门槛继续生效。其他比较按问题和实际样本选择参照，不自动触发完整统计或五篇方案；单篇描述无需参照。

设同口径参照值的最小值为L、最大值为U，均值按逐篇数值的算术平均报告：

| 指标类别 | 该方案的参照区间 | 比较或采纳为门槛时的口径 |
|---|---|---|
| 非词项指标 | `[L, U]` | 总词数、句段长度、词性密度、句法结构、多样性、重复词串比例、邻句重合，以及主语／角色／过程、立场覆盖和推进比例，保持各自单位与可判规则。 |
| 具体词语／固定短语的使用频率 | `[0.8 × L, 1.2 × U]` | 默认用每千词密度判定，原始次数另报；词族汇总或词表类别的使用频率同理。 |

词语的20%是分别相对于两个端点外扩，不是区间宽度的20%或增加20个百分点；全零参照仍为`[0, 0]`。次数与密度的判定不可互相替代。低频词同时说明一次出现对应的密度变化`1000/N`（N为样本词数），保留必要语义；不得为凑下限机械添词，确需保留的越界应明确报告并按已有门槛冲突规则处理。

逐篇先按自己的分母归一化，再等权求均值和min–max；不能用长文章权重更大的合并比例替代篇均值。合并分子／分母可以另列，但明确另一个估计对象。逐项报告参照原始最小值、最大值、均值、有效篇数、本稿分子／分母和差值；已采纳为硬门槛者再列实际门槛与通过结果，用未舍入值判定并报告临界距离。缺失值不当作零；采用五篇参照方案时，不足五篇的指标保留参照不足。所选指标的诊断结果不自动成为验收门槛；单篇特设上限、某期刊样本数值和零防御观察不能自动推广成通用数值规则。禁止防御和内部工作语言的内容要求仍独立有效，低频或零计数不能替代审读。

## 执行顺序

1. **限定文本和科学任务。**从用户指定的文本或批次固定输入，记录章节、学科、体裁、版本和纳入/排除范围；信息明确时直接执行，不重复询问。确认全文、某节、样段或指定句子，以及标题、图注、引文、公式、附录是否纳入。检查提取范围和阅读顺序；解释具体差异时再读有关邻句、邻段，不要求主模型先通读整个批次。
2. **选择指标和规则。**根据问题和已采用约定选择需要的句法、词表、语义维度或词族汇总；明确选用完整组合时按上述范围执行。[语义统计方法](semantic-language-method.md)提供相应编码。保留实际使用的单位、分子分母、方法、未定身份及归一化规则；自动句法只作为明示的估计，词表命中不能充作功能标签。
3. **实际统计所给文本。**短文也须给原始计数、分母和可计算的比例或密度；长度小只限制代表性和异常推断，不免除计数。保留输出和可回查定位，不用一个总分掩盖不同功能。
4. **按任务选择参照。**明确采用五篇目标期刊方案时执行上述规则；其他比较采用适合当前问题及已给定范围的参照，单批描述或版本比较按所给文本执行。文献对照须核来源的计数单位、分母、分类定义、体裁、学科、章节和获取级别。可比时算描述性差值：比例用百分点；归一化频率须用相同单位，注明文本级均值还是合并语料密度。分母可换算但分子定义不同，仍不可直接相减。正式结果片段已有数值与口径时可对照，注明未见原表、样本数等缺项，不据此做显著性检验。仅有方向、单位不可比或缺少适用分层时标“暂无可比数值”，仍报告本稿实测值；不把F值或r²套成单篇显著性或质量公式。
5. **解释差异并给选择。**区分文本观察、文献分布、语料边界和解释。说明差异可能来自任务、章节、学科、体裁、编码口径或样本量；必要时给出保留原写法/可选改写及其组织效果。不可因频率偏离就删掉科学上必要的限制。用户只要分析时不自动改论文文件。

## 现成程序与任务路由

本机使用独立的[论文语言统计程序](/home/weathour/公共/paper-language-statistics/paper_language_stats.py)；参数、数学定义、输出字段和提取边界以其[使用说明](/home/weathour/公共/paper-language-statistics/README.md)为准。复用程序及项目已有的提取、门槛计算入口，统计实现由它们持有。环境缺项记入待完成的量化工作，其余写作照常推进。

| 请求 | 输入与执行选择 |
|---|---|
| 明确只描述单篇或一批材料 | `--a` 指定文件／目录；此类请求不强制提供 B 组 |
| 明确采用完整组合或既有项目验收 | 选用完整英文组合时启用 `--nlp syntax` 并运行内置及补充词表，按方法参考完成语义编码和词族汇总；其他已采用的项目指标按各自范围和参照执行 |
| 两批／本稿与参照论文 | `--a`、`--b`；比较方向为 B−A；分清篇均值与按原始分子分母合并的密度 |
| 修订前后 | 清单记录 `group` A/B 与明确的 `pair_id`，加 `--paired`；不按排序或文件名猜配对 |
| 与发表研究对照 | 先实测，再沿本篇文献锚点核口径；程序不会自动将其输出映射为文献类别 |

以下命令中的输入和输出路径替换为本次任务实际路径；在项目已有分析／产物目录或临时目录保存结果，输出目录须为空或不存在。通用程序的CLI默认 `--nlp none`；需要英文句法或补充词表时，示例显式传入 `--nlp syntax` 或 `--terms`。程序只完成机械部分，所选语义类别或词族去重结果按方法参考另存并关联同一输入。采用正文＋附录篇幅口径时另行核定其清单，不能将叙述样本词数当作全文总词数。

```bash
paper_stats_root=/home/weathour/公共/paper-language-statistics
paper_os_terms=/home/weathour/.agents/skills/yxj-paper-os/assets/language-terms-en.txt
# 示例：明确采用五篇参照方案时，清单包含本稿及所选同刊同类型参照。
"$paper_stats_root/.venv-syntax/bin/python" "$paper_stats_root/paper_language_stats.py" \
  --manifest corpus.jsonl --nlp syntax --terms "$paper_os_terms" --out results-comparison
# 修订前后沿用相同文本范围、解析器和词表。
"$paper_stats_root/.venv-syntax/bin/python" "$paper_stats_root/paper_language_stats.py" \
  --manifest revisions.jsonl --paired --nlp syntax --terms "$paper_os_terms" --out results-paired
# 中文基础统计；当前无对应句法解析器，需另列能力缺项。
python3 "$paper_stats_root/paper_language_stats.py" --a target-zh.txt --language zh --out results-zh
```

带分层或配对的任务优先使用 JSONL 清单。每行一份文档，`path` 相对清单目录，`id` 唯一；同一文稿的 A/B 版本共享 `pair_id`。直接文件／目录模式以不含扩展名的文件名作 ID，重名时改用清单赋唯一 ID，保留原文件名：

```json
{"id":"p1_before","group":"A","path":"before/p1.txt","language":"en","genre":"empirical","pair_id":"p1"}
{"id":"p1_after","group":"B","path":"after/p1.txt","language":"en","genre":"empirical","pair_id":"p1"}
```

精确限制正文、章节或页段时，用经确认的 `blocks` 替代 `path`，格式见程序说明。保留真实段落边界，勿将不相邻的摘句拼成自然段后解释句际推进。PDF／复杂 TeX 自动提取需核读序和范围；位置偏移指向保存的准备后文本，结合页号／章节回查原件。

程序自动按语言、体裁分层；需比较学科时先分别组织输入。章节指标输出在 `section_metrics.csv`，不会自动完成全部章节级批次推断；需要某节的两批比较时，以每篇该节的确认文本组织清单。专著与论文分开描述，同书多章不视为多本独立文献。当前重采样单位是清单文档／文档对，没有书籍聚类重采样；需以书为推断单位时每书一个输入，或仅报告章级描述。单篇参照及非随机小批次不支持总体异常判断。

默认不做重采样；确需区间且独立文档数支持时，可加 `--bootstrap N --seed S`，明确抽样单位和局限。`--terms terms.txt` 接收每行一个精确术语；词束长度、窗口和最低频次沿程序说明设置并随运行保存。比较版本时保持口径与模型相同。

### 中英文适用范围

依据待分析文本判定语言，不依据用户提问语言。程序不自动识别语言；直接输入的默认值是 `en`，调用时显式指定 `--language en` 或 `--language zh`，清单则逐篇填写 `language`。不要用默认英文处理中文后把词表漏检解释为零出现。中英混合批次用逐篇标明语言的清单；同篇的中英文摘要等连续区段应拆开统计，保留同文来源，不当作独立论文样本。中文正文中的少量英文术语可保留，但单一语言词表不能覆盖全部跨语言功能表达。

| 能力 | 英文 | 中文及比较限制 |
|---|---|---|
| 词项与长度 | 以程序定义的词／数字单位计数 | 以单汉字及拉丁词／数字单位计数，尚未中文分词；不直接相减中英文词密度或将默认长句阈值当成等价难度 |
| 词串、TTR／MATTR、熵、Jaccard、共现 | 基于英文词单位 | 基于中文字符等单位，报告为字符／单位串、多样性、重合或共现，不能称为已分词的词汇多样性或词语搭配；公式相同不使跨语言数值可比 |
| 词性与句法 | 需要时启用 `--nlp syntax`，同时包含词性自动估计 | 尚无中文解析器；中文不启用 `--nlp`，混合批次需先拆出英文子集；缺失的中文句法能力不填零 |
| 功能词表 | 按选择使用内置英文有限字面词表及补充词表 | 独立中文词表，主要使用简体字形，不自动繁简转换；两套词表不构成翻译等价编码，不能直接据密度比较中英文立场 |
| 引文与图表公式线索 | 有限数字引文、英文作者—年份及 Fig./Table/Eq. 等模式 | 数字引文与显式占位符可复用；“图1／表2／式(3)”及中文作者—年份未完整覆盖，零命中不表示没有相应指称 |

中文新单位与 `legacy_zh.` 十二项的分母分别保留。中英文研究基线也分别核口径，不把英文语料数值当中文目标。paper-os 主导论文范围、科学含义和取舍，[中文表达技能](../../yxj-chinese-expression/SKILL.md)承接有关中文句段和语体判断。

## 指标口径速查

| 指标 | 本稿的可复核计数 | 归一化与文献对照 |
|---|---|---|
| 词数、句数、句长 | 说明token规则、标题/图注/公式/引文是否纳入；报总词数、句数、均值及必要分布。 | 属于本稿描述；无匹配基线时不造“正常范围”。短文本仍给原始数和分母。 |
| 从句、名词短语及修饰语 | 按明确句法功能逐句编码，如有限if从句、关系从句、非限定修饰、NP前置修饰；检索词后人工核验功能。 | 可按每千词报数，与来源相同功能和口径比较。if字符串命中≠if从句数；attributive adjectives次数≠含形容词NP数；PP作修饰语须核附着及语义功能。 |
| 主动/被动、主语语义角色、过程类型 | 主语／角色／过程各用可判主句分母并报未定。语态手工分类与程序的被动候选率分开声明各自分母，不能以主语分母替换程序原单位。 | 本地类别若不与原研究定义精确匹配，只并列描述，不声称同口径。SFL transitivity是过程类型系统，不等于普通及物/不及物二分。 |
| this/these指称 | 逐个有效出现分类determiner或pronoun；分母为该篇有效this/these总数，分别报数和比例。 | 按相同类别与出现单位比较。裸词检索后须排除非指示用法、引文和不符合范围项；比例小样本易变。 |
| 词束、搭配 | 分开报连续词串type数、token数、跨文档分布；明确长度、词形归并、边界和频率阈值。 | 一篇文章只能说明该文重复串，不能冒充Cortes跨至少5篇筛出的词束库；跨语料比较须匹配文档数及阈值。 |
| 条件、量词/否定范围、时态情态 | 先检索候选，再按作用范围、命题关系和语境分类；报候选数、可判数、各类数/比例及代表性定位。 | 词项命中不等于条件、hedge或否定范围。文献无同口径表时保留“暂无基线”，不从摘要方向造比例。 |
| 立场、读者互动、重复退让 | 按来源定义逐例分功能；必要时分开认识保留、态度、增强、读者互动、泛化免责声明及重复claim-retreat。 | 不能把hedging自动等同防御；重复退让须有语境编码。现有研究未验证普适“过度防御”指标或阈值。 |
| Theme、指称链、句际推进 | 默认主要话题推进按同段原相邻句对编码，段首单列，报全部对、可判对、类别比例及未定；正式Theme/Rheme或given/new另按所选研究定义编码。 | 默认推进不是完整Theme理论标注；话题不等于形式主语。不得把未读上下文的指称猜成已知信息。 |

|---|---|---|

| 从句与修饰 | 英文从句候选、直接名词修饰链接、主谓头距离 | 附着关系、完整短语及与研究分类的一致性 |
| 语态与角色 | 英文被动、完成、进行等句法候选 | 主语语义角色、过程类型、语态的组织作用 |

名称保留方法，如“保留词表命中”“被动句法候选”，不能缩写成已核定的功能比例。不同指标各自保留分子、分母、方法和未定项。抽回有关原句核语法／语义；自动解析估计可直接报告，但不据少量抽查宣称全部分类已核准。字面重合、熵或长度变化只提示差异，没有统一好坏方向。

## 限定与防御性的语境判断

程序命中用于定位；采用全文立场编码时仍覆盖声明范围内的未命中句，并回读必要邻文。按[默认定义](semantic-language-method.md#stance)区分实质条件、认识不确定性、技术可能、具体负面结果、泛化免责声明及重复主张—退让；这些功能可重叠，不从词频推断“过度防御”。

选择全文语义分析时交付有分母的比例及定位解释；局部诊断沿用户范围执行。只编码词表命中的候选，就只报告候选内比例，不能冒称全文语义分布；抽样估计需交代设计、权重和适用误差。模型辅助编码记录实际方法与复核范围，多次或多模型一致不自动确立分类真值。

Laya 的现有论文试用不足以支持句子功能、不确定性或结论范围的正式自动计数。仅在明确需要候选筛选时，按程序说明单独运行 `laya_candidates.py`；候选标签及置信度不进入正式指标、比较表或质量判断。核定后的语义计数另列方法和来源，不冒称程序原生输出。

表达修订使用 [条件与范围的安置方法](authorial-style.md#conditions-in-the-argument)：将实质内容落实到定义、假设、数学关系、比较或讨论，消除重复的主张—退缩组织。本节负责定位和计数，具体写法由该方法承担。

## 可核对的文献数值锚点

以下数值便于建立口径，不是目标阈值：

- **句法功能（Biber, Gray & Poonpon 2011）**：429篇研究论文与723份会话文本、28项特征，表4–6按每千词报告；if从句为会话4.0、论文1.1次/千词；attributive adjectives为会话16.5、论文57.1次/千词（表4、6；PDF pp.18、20）。检索if须逐句确认是从句，形容词计数不能改写成“含形容词名词短语”计数。与Biber & Gray 2010语料重叠，不是独立复现。
- **立场（Hyland 2005）**：240篇、8学科、约140万词；表1总语料hedges为14.5次/千词，表2机械工程为8.2次/千词，哲学18.5、营销20.0次/千词。分母均为词数归一化；不能按单篇应有密度解读，也不代表目标文本的hedge机会数。具体表格和定位见源卡。
- **this/these（Gray & Cortes 2011）**：应用语言学样本79%作determiner，材料/土木工程（MCE）样本83%作determiner；对应pronoun为21%和17%。分母为该来源分类的this/these出现，非词数。出版社索引未给样本文章数、完整表和检验，故只作摘要/索引级比例，不推出用法规则。
- **篇章结构（Maswana等2015）**：67篇五类工程论文，由6名领域研究者编码12个moves、38个steps；表3“回顾既有研究”覆盖率86–100%，每篇1.3–4.9次。文章覆盖率与每篇出现均值是不同指标，不混成一个比例。
- **条件句（Carter-Thomas & Rowley-Jolivet 2008）**：442个跨医学论文、会议报告和社论的if实例中，典型时态序列占14.7%；RA子集占5.9%，社论Discourse Management占1.8%。各体裁分母和完整表缺失，不能据总数构造目标RA基线。

来源载体、页表定位和获取级别应沿源卡复核。Hyland 2005原表已视觉核对；Biber 2011表4–6已视觉核对；Gray/Cortes与Carter-Thomas数值来自出版社索引/摘要片段，未见原表图像。Martínez 2001虽有出版社Results索引给出计数，但未核原表；Martínez 2003、Gosden等详细分布不可得。对这些研究可沿其分类理解问题，不能把摘要方向伪装成精确基线。

## 短段演示（自拟，不是发表例句）

文本：“The model predicts delay effects. This prediction guides controller design. This remains useful under bounded delay.” 以空格分词、句号切句，3句共16词。只统计指示性this/these：第2句“This prediction”作determiner，第3句“This”作pronoun。因此determiner为1/2=50%，pronoun为1/2=50%。若与MCE来源的83% determiner相比，差为−33个百分点。这个小段只有2个观察，比例易受单个用例影响；差值不表示质量异常或改写义务。实际稿件需按用户指定范围计数并说明排除规则。

## 结果呈现与边界

先读 `run.json` 的输入、口径与警告，再从 `comparison.json` 或指标 CSV 提取与请求有关的值；解释某项差异时，按文档／句子身份读取 `occurrences.jsonl`、`sentences.jsonl` 及准备后上下文。词束问题再取 `lexical_patterns.json`。完整结果留作回查，无需把所有文章、指标和命中送入模型上下文；程序 `report.md` 是全量数值报告，面向用户的解释仍按当前问题组织。

复用已有结果前核对输入哈希、纳入范围、参数、程序与解析模型身份；当前程序没有自动缓存。复用条件不符时重算受影响输入／比较。报告分别呈现实测发现、原句解释和写作选择，保留零观察与缺失值的区别。

优先用紧凑表格呈现：**指标／方法｜各组或版本的分子／分母与实测值｜可比差值｜定位与解释**；单批只列实测，请求文献对照时再加入文献样本、数值及可比性。正文补充功能分类实例和对科学任务的解释。若文献缺所需基线数值，或分类与分母单位无法确认，不填差值；仍交付本稿实测和真实缺口。已知比例但原始样本数未知时，可报描述性百分点差，注明证据范围，不能据此估计统计显著性。不同体裁或章节保留分层，不直接合并均值。

发表研究中的分布描述其样本。本篇给出可选参照方案的区间及其采纳方法，明确硬门槛才要求同版本逐项通过；不把所选报告项、既有单篇项目的比例或参照极值当作普适质量标准。频率差异仍须由科学任务和实际表达解释，hedging与防御性写作分别按语境判断。实验论文、会议摘要、学位论文和学生文本各按适用稿型比较。量词／否定、拆合句、句末焦点等缺少可比数值时，保留为本稿观察。
